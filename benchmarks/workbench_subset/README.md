# WorkBench 单任务适配样例

这里保存本项目第一条 WorkBench 适配任务所需的最小数据子集。

- 来源仓库 https://github.com/olly-styles/WorkBench
- 固定来源提交 `49c7dfd00c03d384ec59ea57374f50b766aa5613`
- 原始任务位于 `multi_domain_tasks_and_outcomes.csv` 的第 31 条数据行，使用 0-based 索引时为 30
- 原始仓库采用 MIT License，许可证副本保存在本目录的 `LICENSE`

本样例保留日历和邮件数据库，用于执行一条“先查找指定日期的第一场活动，再给参会人发送提醒邮件”的任务。它是本地适配验证，不代表完整 WorkBench 690 条任务的正式成绩。
